# Escalation — 升級格式

## 標準升級報告格式

所有升級報告必須遵循以下標準格式：

```markdown
## 升級報告
**問題描述**：[具體描述]
**已嘗試方案**：[列出已試過的解決方式]
**推薦選項**：[你的建議]
**影響範圍**：[受影響的 Stories / 時程]
```

---

## 欄位說明

| 欄位 | 說明 |
|------|------|
| 問題描述 | 清楚描述問題的本質與背景，讓接收方無需額外詢問即可理解 |
| 已嘗試方案 | 列出已試過的解決方式與失敗原因，避免重複嘗試 |
| 推薦選項 | 提出至少一個具體建議，附帶優缺點分析 |
| 影響範圍 | 標明受影響的 Stories、Sprint 時程、或相依功能 |

---

## 升級前檢查

升級時必須附帶以下三項，缺少任何一項則退回補齊後再升級：

1. **問題描述** — 具體描述，非模糊陳述
2. **已嘗試的方案** — 至少嘗試過一個解決方案
3. **推薦的選項** — 至少一個具體建議
