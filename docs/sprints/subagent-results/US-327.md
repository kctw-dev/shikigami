## 完成摘要

## 修改內容

### skills/cruise/SKILL.md

1. **新增「自動行動決策表」子段**（AC-1）
   - 4 種情境：新回覆排入 Backlog、內部 Issue 直接回覆、無 label 自動 Triage、awaiting-reply 超時催促
   - 安全前置檢查：stakeholder label → 跳過所有行動

2. **交付推進自動化**（AC-2）
   - 交付鏈：`staging → E2E → tag → production → close`
   - PR merge 後自動推進，推進前檢查前置條件（避免跳步）
   - log action 類型：`"push-delivery"`

3. **awaiting-reply 超時催促**（AC-3）
   - 判斷 `awaiting-reply` label + 最後留言超過 24h
   - 冪等性：最後留言已是自動催促 → 跳過
   - 頻率上限：每 Issue 每天最多 1 次
   - log action 類型：`"nudge"`

4. **無 label 自動 Triage**（AC-4）
   - 無 label Issue → invoke `issue-management` triage
   - 已有 label 不重複 triage（冪等性）
   - log action 類型：`"triage"`

5. **新增§安全邊界段落**（AC-5）
   - 判斷標準：`stakeholder` label
   - Stakeholder Issue 只記錄至 cruise log，不自動行動
   - log 標注：`"skipped": "stakeholder-issue"`

6. **Cruise log 行動類型擴充**（AC-6）
   - 新增類型：`"reply"` / `"triage"` / `"push-delivery"` / `"nudge"` / `"skipped"`
   - 更新 Log 格式完整範例
