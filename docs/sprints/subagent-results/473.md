### 決策摘要

ADR-033 包含以下 5 個核心決策：

1. **格式**：JSONL，每行一筆 span（否決文字格式與 SQLite）
2. **Schema**：traceId / spanId / parentSpanId / agentRole / action / timestamp / status / sessionId（必要）+ duration / storyId / metadata（可選）
3. **寫入插入點**：Agent 層 Skill.md 顯式記錄為主方案；Hook 層預留為未來可選補充
4. **儲存策略**：per-session 檔案 `docs/trace-logs/{date}-{session-id}.jsonl`，7天 retention（可配置）
5. **與既有 log 關係**：三層獨立（trace/cruise/live），各有職責，互補不重複
