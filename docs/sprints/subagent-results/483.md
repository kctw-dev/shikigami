## 執行摘要

### AC1 — Trace Log 完整性指標規範 ✅

建立 `docs/km/trace-log-completeness-spec.md`：
- 定義 ADR-033 規定的 8 個必要欄位（traceId/spanId/parentSpanId/agentRole/action/timestamp/status/sessionId）
- 完整性指標公式：完整 span 數 / 總 span 數 × 100%
- 健康門檻：HEALTHY（≥100%）/ WARNING（80-99%）/ CRITICAL（<80%）
- parentSpanId 參照完整性規則（null 合法、跨 session 引用為 WARNING 非 ERROR）
- 與 validate-trace-log.sh 及 quality-observer MCP 的對應關係

### AC2 — 自動化 Trace 驗證腳本 ✅

建立 `scripts/validate-trace-log.sh`：
- JSONL 格式合法性驗證（每行為合法 JSON 物件）
- 8 個必要欄位存在性驗證
- parentSpanId 參照完整性（孤立引用為 WARNING，跨 session 容許）
- per-session 命名格式驗證（YYYY-MM-DD-{session-id}.jsonl）
- status 合法值驗證（started|completed|failed）
- 空目錄正常 exit 0（初始狀態合法）
- 整體覆蓋率統計輸出

### AC3 — quality-observer MCP trace 查詢擴充 ✅

修改 `mcp-servers/quality-observer/index.js`，新增三個 tool：
- `get_trace_recent`：查詢最近 N 條 trace span（預設 20，最大 200）
- `get_trace_by_session`：按 session ID 篩選所有 span（依 timestamp 升序）
- `get_trace_summary`：human-readable 摘要（覆蓋率、agentRole/status/action 分佈）
