### AC-2：檔案鎖定 acquire/release API 實作

- **新增** `hooks/acquire-file-lock.sh`
  - 參數：`<relative_file_path> [issue_id]`
  - Path hash：`echo "$REL_PATH" | sha256sum | cut -c1-16`
  - Ref namespace：`refs/file-locks/<hash>`
  - flock 本地鎖（若可用）+ git push 遠端鎖
  - 輸出：`[FILE-LOCK-OK]` / `[FILE-LOCK-BLOCKED]`（含鎖持有者 session/path/age）/ `[FILE-LOCK-STALE]`
  - 失敗不阻塞（set +e / || true）

- **新增** `hooks/release-file-lock.sh`
  - 參數：`<relative_file_path>`
  - `git push origin --delete refs/file-locks/<hash>`
  - 清除本地 metadata（`/tmp/shikigami-file-locks-<repo_fp>/`）
  - 輸出：`[FILE-LOCK-RELEASE]`

### AC-3：TTL 自動釋放機制

- TTL = 1800 秒（30 分鐘）
- `acquire-file-lock.sh` 在 acquire 前偵測 stale lock：
  - `git ls-remote origin` 取得 ref 的 commit time
  - `AGE_SECONDS >= 1800` → 強制清除，輸出 `[FILE-LOCK-STALE]`，繼續 acquire
  - `AGE_SECONDS < 1800` → 輸出 `[FILE-LOCK-BLOCKED]` 含持有者資訊，拒絕
- 降級策略：remote 不可用 → `[WARN]` 降級為本地 flock-only，不阻塞
