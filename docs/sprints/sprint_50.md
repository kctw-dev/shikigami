### US-99：shikigami:diagram 文件整合 — 自動嵌入 Markdown、Issue 回覆附圖、關閉 #89

**來源**：Issue #98（Issue #89 子 Story C）
**Size**：S / 1 Point
**Owner**：Developer
**QA doc-only 判定**：Yes（SKILL.md 補充段落為靜態文件；AC3 Issue 關閉為文件操作）
**父 Issue**：#89（feat: shikigami:diagram 技能）
**前置 Story**：US-98（#97）— Sprint 49 完成

**User Story**

As a Developer subagent, I want SKILL.md to include step-by-step guidance for embedding diagram outputs into Markdown files and attaching diagrams to GitHub Issue comments, so that architecture diagrams generated by the `shikigami:diagram` skill can be seamlessly shared within Sprint documentation and Issue discussions without manual lookup.

**背景**

子 Story B（US-98）完成後，SKILL.md §5.2 指出 PNG/SVG 需手動匯出，但對於嵌入 Markdown 或回覆 GitHub Issue 的具體操作流程，缺乏明確指引。Sprint 49 Retro Action Item #1 識別此缺口，本 Story 補充這兩個文件整合場景，使技能交付完整，並關閉父 Issue #89（Issue #89 子 Story A、B、C 全數完成）。

**Acceptance Criteria**

| # | 類型 | 條件 | 通過標準 |
|---|------|------|----------|
| AC1 | [靜態] | SKILL.md 補充自動嵌入 Markdown 步驟 | `skills/diagram/SKILL.md` 新增「嵌入 Markdown」段落，說明 diagram 完成後將圖片自動插入至指定 .md 文件的操作步驟（包含：匯出路徑規範、Markdown 圖片語法、插入目標文件的定位方式） |
| AC2 | [靜態] | Issue 回覆附圖指引 | `skills/diagram/SKILL.md` 新增「GitHub Issue 回覆附圖」段落，說明 diagram 完成後提供 GitHub Issue comment 附圖的操作指引（包含：上傳圖片至 GitHub、取得圖片 URL、在 Issue comment 中使用 Markdown 語法附圖） |
| AC3 | [文件] | Issue #89 關閉 | 父 Issue #89 所有子 Stories（A、B、C）均完成後，以 comment 說明完成摘要並關閉 #89 |
