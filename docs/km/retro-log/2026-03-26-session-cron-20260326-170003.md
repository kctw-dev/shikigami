## Problem（遇到的問題）

1. **sprint-metrics-trend.sh `set -e` 陷阱**：`set -euo pipefail` 導致 `grep` 找不到匹配時腳本非零退出。須改用 `set -uo pipefail` + `|| true`，此為 shell 腳本常見坑，缺乏規範文件說明。
2. **adr-status-dashboard.sh 測試假陽性**：footer 說明文字含 `[ADR-STALE]` literal，導致 grep 誤判。需注意測試文字不可在腳本輸出的說明段落中含有 sentinel 字串。
3. **subagent-results/*.md gitignore 衝突**：`.gitignore` 封鎖了 `docs/sprints/subagent-results/*.md`，需要用 dot-file marker（`.story-899-done`）替代。gitignore 規則與流程文件未同步說明此衝突。
4. **claim-issue.sh CLAIM-BLOCKED 殘留鎖**：前次 claim attempt 的 flock 未清理，需手動 release 才能重新 claim，增加摩擦。
