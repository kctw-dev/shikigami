# 設計師協作指南

**給誰看**：使用 Figma 的設計師
**一句話摘要**：你只管在 Figma 畫，AI 團隊負責把設計變成程式碼

---

## 你做什麼、AI 做什麼

| 你（設計師） | AI 團隊 |
|-------------|---------|
| 在 Figma 畫設計 | 讀取你的 Figma 設計 |
| 用 Figma Variable 設定顏色 | 轉成前端程式碼 |
| 看截圖確認結果 | 自動修正到跟設計一致 |

**你不用寫程式、不用管開發進度、不用知道現在第幾個 Sprint。**

---

## 怎麼交付設計

```
1. 在 Figma 畫好設計
2. 告訴 PO「設計好了」（貼 Figma 連結或口頭通知都行）
3. AI 團隊會自己來讀取、產出、比對
4. 你看最終截圖，不滿意就告訴 PO 哪裡要改
```

就這樣。剩下的是 AI 團隊的事。

---

## 在 Figma 裡你可以自由做的事

- 自己開 Page，用你習慣的方式命名
- 自由安排畫框（Frame）的位置和大小
- 用你習慣的方式組織圖層
- 隨時修改設計，改完通知 PO 就好

**AI 團隊會自動處理**：把你的設計對應到開發任務、整理命名、歸檔舊稿。你不需要管這些。

---

## 唯一要注意的兩件事

### 1. 顏色請用 Figma Variable（變數），不要手打色碼

為什麼？因為 AI 讀的是 Variable 名稱，不是色碼。用 Variable = AI 產出的顏色跟你設計的一致。

**怎麼用**：選取元件 → 填色欄位 → 點小方塊圖示 → 選 Variable

目前可用的主要顏色：

| Variable 名稱 | 顏色 | 什麼時候用 |
|--------------|------|-----------|
| `color/primary/500` | 🔵 藍色 | 主要按鈕、重點連結 |
| `color/danger/500` | 🔴 紅色 | 刪除、錯誤 |
| `color/neutral/0` | ⬜ 白色 | 背景、按鈕文字 |
| `color/neutral/200` | 淺灰 | 邊框 |
| `color/neutral/400` | 中灰 | 提示文字 |
| `color/secondary/700` | 深灰 | 內文文字 |
| `color/secondary/900` | 近黑 | 標題 |

> 需要新顏色？不要手打色碼，告訴 PO「我需要一個 XXX 用途的顏色」，團隊會新增 Variable。

### 2. 元件庫裡有的元件，請直接拉來用

`_Component-Library` 這個 Page 裡有現成的元件：

| 元件 | 有哪些樣式 |
|------|-----------|
| **Button**（按鈕） | Primary（藍）、Secondary（灰）、Danger（紅）、Ghost（透明） |
| **Input**（輸入框） | 預設、輸入中、錯誤、停用 |
| **Card**（卡片） | 標準（有陰影）、懸浮（大陰影）、外框（有邊框） |

> 需要新元件（例如彈窗、下拉選單）？直接在 `_Component-Library` 裡建就好，記得用 Variable 設定顏色。

## 常見問題

**Q：我不知道現在是第幾個 Sprint，Page 要怎麼命名？**
不用管 Sprint 編號。你自己開 Page，用你覺得清楚的名字就好（例如「登入頁設計」「Dashboard v2」）。AI 團隊會自己對應。

**Q：圖層一定要用英文命名嗎？**
不用。用中文、英文都行。盡量讓名字表達「這是什麼」而不是「Frame 1」「Group 2」就好。

**Q：我改了設計，AI 會自動更新嗎？**
不會自動更新。改完通知 PO，AI 會在下一輪重新讀取。

**Q：我可以用 Token 清單以外的顏色嗎？**
可以先用，但請告訴團隊。團隊會把它加進 Variable 清單，這樣其他地方也能統一使用。

**Q：我對 AI 做出來的結果不滿意怎麼辦？**
告訴 PO 哪裡不對。附上你的 Figma 設計截圖和 AI 產出的截圖，指出差異，AI 會重新調整。

**Q：我需要裝什麼軟體？**
只需要 **Figma**（桌面版或網頁版都行）。
